# iPad 畫布視窗 (iPadCanvas)

macOS 視窗化 iPad 螢幕鏡像工具（支援 Wi-Fi AirPlay / USB 有線直連）。  
獨立視窗顯示、支援 `Cmd + Tab` 自由切換，專為一邊在 iPad 作畫、一邊在 Mac 監看設計。

---

## 快速使用

1. **啟動程式**：開啟 `iPadCanvas.app`（或終端執行 `./build_app.sh && open iPadCanvas.app`）。
2. **連線 iPad**：
   - **無線 (Wi-Fi)**：iPad 滑出「控制中心」→「螢幕鏡像輸出」→ 點選 **「iPad 畫布視窗」**。
   - **有線 (USB)**：連接傳輸線，於頂部控制列切換至「USB 有線」即可。

---

## 快捷鍵一覽

| 快捷鍵 | 功能 |
| :--- | :--- |
| **`⌥ Space`** | 全局顯示 / 隱藏 iPad 畫布視窗 |
| **`⌘ Tab`** | 正常在 Mac 軟體間自由切換視窗 |
| **`⌘ T`** | 視窗置頂 (Always on Top) 開關 |
| **`⌘ B`** | 無邊框純淨模式（隱藏標題列，任意位置可拖曳） |
| **`⌘ F`** | 水平鏡像翻轉（畫圖即時檢查構圖與人體骨架） |
| **`⌘ R`** | 順時針旋轉 90° |
| **`⌘ 0`** | 自動貼合 iPad 畫面長寬比（消除黑邊） |
| **`⌘ C`** | 複製當前 iPad 高畫質畫面至剪貼簿 |
| **`⌘ S`** | 儲存當前畫面截圖至桌面 |
| **`⌥ E`** | 滑鼠點擊穿透模式（將半透明畫布疊在參考圖上描圖） |

## 編譯與建置

### 依賴環境
```bash
brew install openssl@3 libplist
```

### 建置應用程式
```bash
./build_app.sh
```
編譯完成後產物為 `iPadCanvas.app`。
